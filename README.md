# job-scout

> **Work in progress — not usable yet.** This repo is being built milestone by milestone; see `ROADMAP.md`.

An agent skill that reads your resume, confirms a short search brief with you, then checks employer job boards directly (Greenhouse, Ashby, Lever) and returns about 15 roles that are open today — each linked straight to the employer, with fit reasons quoted from the job description.

- **Status:** Current release: `0.0.1` (scaffold only).
- **Spec:** [`docs/HANDOFF.md`](docs/HANDOFF.md). **Plan:** [`implementation-plan.yaml`](implementation-plan.yaml).

job-scout is not affiliated with any job board or employer.
